# Registro de decisões (ADRs)

Cada arquivo registra uma decisão: contexto, decisão, consequências. ADRs não são editados depois de aceitos; uma decisão nova cria outro ADR que diz qual substitui.

Formato do nome: `NNNN-titulo-curto.md`. Status: proposto, aceito, substituído por NNNN.

| ADR | Decisão | Status |
|---|---|---|
| 0001 | Notação primeiro, áudio plugável | aceito |
| 0002 | Produto comercial e política de licenças | aceito |
| 0003 | Score IR como contrato único, com camadas listen e notation | aceito |
| 0004 | Editor assistido antes da API pública | aceito |
| 0005 | Documentação em `docs/` como fonte de contexto para humanos e IA | aceito |
